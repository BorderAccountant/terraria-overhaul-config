## 🚀 Features

| **Feature** | **Description** |
|:---|:---|
| **Combat Settings** | Adjust Overhaul's dodge mechanic and blood particle intensity |
| **Seasons Config** | Enable or disable seasonal effects and weather frequency |
| **Camera Tweaks** | Tune screen shake, zoom and follow smoothness settings |
| **Survival Mechanics** | Configure temperature, drowning and other survival feature thresholds |
